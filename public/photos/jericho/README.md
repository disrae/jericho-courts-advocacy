# Jericho court photos

Drop your images here with these exact filenames:

| File | Use this photo |
|------|----------------|
| `worn-net.jpg` | Close-up of frayed/worn net binding |
| `broken-net-tape.jpg` | Net post held with tape, broken hardware |
| `portable-net-lines.jpg` | Net with overlapping red/white court lines |
| `courts-busy.jpg` | Wide shot — multiple games, courts full |
| `active-play.jpg` | Player on court, fence with court numbers |
| `evening-demand.jpg` | Dusk — spectators, no lights (hero image) |
| `extra-01.jpg` | Your extra image |

Captions live in `data/site-photos.json`. Edit there if wording needs to change.

Cropping/focus is controlled via `objectPosition` in that file — no need to pre-crop.
