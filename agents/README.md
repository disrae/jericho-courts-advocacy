# Agents

This folder is the **task queue and coordination layer** for AI agents working the Jericho courts campaign.

## Start here

1. [`tasks/BACKLOG.md`](tasks/BACKLOG.md) — pick the highest open task
2. [`../docs/AGENT_WORKFLOWS.md`](../docs/AGENT_WORKFLOWS.md) — rules and autonomy
3. [`../docs/STRATEGY.md`](../docs/STRATEGY.md) — context

## Definition of done

A task is done when:

- Outputs land in the correct `data/` or `docs/` or `campaigns/` path
- Sources are cited with URLs and dates
- BACKLOG item checked off
- Changes committed with a clear message
